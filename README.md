# North Cell Towers

Public bug reports and feature requests for **North Cell Towers**, a native iOS app for exploring Canadian cellular sites, frequencies and antenna information.

This repository contains the public support and privacy pages, feedback documentation and Issue forms. The iOS app's source code is not published here.

## Submit feedback

- [Report a bug](https://github.com/maigougou/NorthCellTowers/issues/new?template=bug_report.yml)
- [Request a feature](https://github.com/maigougou/NorthCellTowers/issues/new?template=feature_request.yml)
- [Browse existing issues](https://github.com/maigougou/NorthCellTowers/issues)

Reports in **English, French or Simplified Chinese** are welcome. Search existing issues first; add useful details to a matching report or react with a thumbs-up to support a request. Please keep each issue focused on one problem or idea.

For bugs, include the app version/build, device model, iOS version, steps to reproduce, and what you expected. For site or frequency discrepancies, also include the carrier, the reported site's coordinates or identifier, the database version/date if available, and active filters. Screenshots or short recordings help explain visual problems.

Issues and attachments are public. Remove personal information, private notes and your device's location from screenshots before posting. Reported tower coordinates can be included when relevant.

## Tracking progress

Bug reports receive `bug`; feature requests receive `enhancement`. Both start with `status:needs-triage`.

| Status | Meaning |
| --- | --- |
| `status:needs-triage` | Awaiting an initial review |
| `status:needs-info` | More details are needed to assess the report |
| `status:confirmed` | Reviewed and accepted for tracking |
| `status:in-progress` | Work is underway |
| `status:blocked` | Waiting on a dependency or prerequisite |

Maintainers replace the status label as work progresses. `priority:high` identifies urgent work; `area:data` identifies site, carrier or frequency data questions. Completed issues are closed with the resolution and, where applicable, the app version/build containing the fix. Duplicates link to the existing issue. Tracking a request does not promise a delivery date.

## Data source

North Cell Towers uses ISED Spectrum Management System data. Reported installations and antenna parameters are not measured coverage or live service guarantees.

App and data reports can both start here. North Cell Towers is not affiliated with ISED, the Government of Canada or any carrier.
